# Maya Chen Portfolio

A dark-mode portfolio for a senior frontend engineer, built with React, TypeScript, and Vite.

## Local development

```bash
npm install
npm run dev
```

The development server will print its local URL. Create a production build with:

```bash
npm run build
```

Run static checks with:

```bash
npm run lint
```

## Deployment

This project is ready to deploy to Vercel.

1. Push the repository to GitHub.
2. Import the repository in Vercel.
3. Use the default Vite settings: build command `npm run build` and output directory `dist`.
4. Deploy.

Update portfolio content in `src/App.tsx` and visual styles in `src/App.css`. The page metadata is maintained in `index.html`.
